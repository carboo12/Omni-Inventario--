Solucionar error Cannot read properties of undefined (reading 'totalRevenue') en la página /reports.

Problema:
Al ingresar a la vista de reportes (/reports), la aplicación se rompe mostrando una pantalla de error no capturado (unhandled exception) debido al intento de acceder a totalRevenue cuando el objeto de datos de la API aún no se ha cargado o es undefined.

Requerimientos de Solución:

Protección y Valores por Defecto en el Frontend:

Inspecciona el componente que renderiza la vista /reports (ej. src/pages/reports.tsx o src/app/reports/page.tsx).

Aplica encadenamiento opcional (optional chaining) y valores de respaldo (fallbacks) en todas las lecturas de propiedades del objeto de métricas:

TypeScript
// Ejemplo de protección segura:
const totalRevenue = data?.totalRevenue ?? 0;
Agrega validación de estado de carga (loading state) o skeletons mientras la petición a la API se completa para prevenir renderizados prematuros.

Manejo Seguro de Errores de API:

Si la petición a la API falla o retorna null, el componente debe mostrar un estado controlado en español (ej. "No se pudieron cargar las métricas de reportes") en lugar de tumbar la interfaz completa.

Verificación de Endpoint Backend:

Revisa el controlador/servicio de reportes que responde a esta ruta y confirma que el JSON retornado incluya siempre la propiedad totalRevenue (incluso si no hay ventas registradas, devolviendo 0).
